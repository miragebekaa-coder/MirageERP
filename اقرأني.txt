ميراج ERP — الترقية ٢٨: ضبط النطاق وكشف التجاوز
================================================

خطوة ١ — قاعدة البيانات (مرة واحدة)
  افتح Supabase ← SQL Editor ونفّذ:
  not in system/28_attendance_guard.sql
  (بعد 27_attendance.sql)

خطوة ٢ — الملفات
  انسخ هذه الملفات فوق القديمة في:
    mirage-erp\
    mirage-erp\upload to Netlify\
  ثم ارفعها إلى GitHub / Netlify.

  checkin.html          صفحة المسح — تمنع التسجيل من خارج النطاق
  attendance.html       سجل الدوام + تبويب «تسجيلات تحتاج مراجعة»
  admin.html            لوحة مدير النظام + ضبط النطاق
  admin\attend.js       حفظ السياسة الجديدة
  mirage-api.js         بصمة الجهاز ومعالجة الرفض
  notifications.html    لون تنبيه الاشتباه

خطوة ٣ — الضبط
  لوحة مدير النظام ← الدوام ← سياسة الدوام ← ضبط النطاق:
  «التسجيل من خارج النطاق» = يُرفض  ← هذا ما يغلق الثغرة.

  وتأكّد أن لكل موقع إحداثيات ونصف قطر صحيحين،
  وإلا لم يكن للنطاق معنى.
